# 🏛️ Institute of Digital Risk (IDR)

This project is a **simple brand and responsive homepage** designed for the **Institute of Digital Risk (IDR)**.  
The website represents an industry-led institute focused on training and deploying professionals in **digital, cyber, and AI risk management**.

---

## 📌 Project Overview

The objective of this assignment was to design:

🎨 **A logo for IDR**  
🌐 **A responsive single-page homepage**

The website explains the institute’s **mission, services, and community** while demonstrating modern web design practices using **HTML, CSS, and JavaScript**.

---

## ✨ Features

✔️ Responsive homepage (Desktop + Mobile)  
✔️ Sticky navigation bar  
✔️ Smooth scrolling navigation  
✔️ Hero section with call-to-action button  
✔️ About section explaining the institute  
✔️ Service pillars displayed using cards  
✔️ Community section  
✔️ Contact form  
✔️ Modern UI with hover effects  

---

## 🎨 Logo Design

The logo uses a **geometric cube** to represent **structure, stability, and resilience** in digital systems.

🟧 **Orange** → Innovation and technology  
⚫ **Black** → Professionalism and strength  
⚪ **White** → Simplicity and clarity  

The cube icon also works independently, making it suitable for **favicons and mobile headers**.
